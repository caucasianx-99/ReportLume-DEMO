Import your X Content CSV

Start with an X Analytics Content CSV that you are authorized to use. Review the preview and confirm when the metrics were downloaded. The original CSV file is not retained.

Before you begin

X makes Analytics and its CSV export available to accounts on a paid X Premium plan that includes Analytics.

Export the Content data from the X account's analytics tools and save it as a CSV file. The file must include post IDs, publication dates, post text and available performance metrics.

Reportlume does not connect to X or download files on your behalf. Export availability and menu names depend on X's current account and analytics options.
